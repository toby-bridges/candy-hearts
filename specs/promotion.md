# Promotion Strategy: 分手照片仪式

**Created**: 2026-01-10
**Status**: Planning
**Target**: 年轻女性（18-35岁）

---

## 核心定位

### 一句话描述
> "一个帮你体面告别的照片仪式"

### 品牌调性
| 是 | 不是 |
|----|------|
| 温暖、陪伴 | 冷冰冰的工具 |
| 仪式感、治愈 | 快餐式修图 |
| 尊重、不评判 | 说教、指导 |
| 女性力量 | 受害者叙事 |
| 私密、安全 | 社交分享 |

### Slogan 候选
- "有些照片，值得一个体面的告别"
- "不是删除，是放下"
- "你有权决定，谁留在你的故事里"
- "封存、抹除、或珍藏——你说了算"

---

## 目标用户画像

### 核心用户：刚分手的年轻女性

| 维度 | 描述 |
|------|------|
| 年龄 | 20-30岁 |
| 性别 | 女性为主（85%+） |
| 状态 | 分手1周-6个月内 |
| 痛点 | 不知道怎么处理合照，删也不是留也不是 |
| 行为 | 深夜刷手机、反复看旧照片、搜索"分手怎么办" |
| 平台 | 小红书、抖音、微博、豆瓣 |

### 次要用户

| 类型 | 场景 |
|------|------|
| 丧亲者 | 处理与逝者的合照 |
| 离婚者 | 处理婚纱照、家庭照 |
| 友谊破裂 | 处理与前闺蜜的合照 |
| 家庭矛盾 | 处理与断联家人的合照 |

## 推广阶段

### Phase 0: 冷启动（MVP上线后）

**目标**: 获取前100个真实用户

**策略**: 精准投放 + 个人故事

#### 1. 小红书种子用户
- 在情感类帖子下留言（不打广告，只分享）
- 发布"我做了一个小工具"的真诚帖子
- 找3-5个小博主做真实体验（不付费，换故事）

**帖子模板**：
```
姥爷去世后，姥姥烧了他们所有的合照。
我理解她的痛，但我也失去了和姥爷的最后连接。

所以我做了这个工具——
不是帮你删照片，是帮你"体面地告别"。

你可以：
📦 封存：模糊处理，等你准备好再看
🖌️ 抹除：把他从照片里抹掉，留下你自己
💌 珍藏：加一句话，变成一段完整的故事

没有账号，不收集数据，照片不会离开你的手机。

链接在评论区。如果你也有不知道怎么处理的照片，试试看。
```

#### 2. 豆瓣小组
- 目标小组：「分手后」「情感树洞」「单身女性」
- 发帖风格：分享创作故事，不是推广产品
- 回复有类似困扰的帖子

#### 3. 微信私域
- 发朋友圈讲述创作故事
- 建立"产品反馈群"（限30人）
- 收集真实用户故事

### Phase 1: 内容营销（100-1000用户）

**目标**: 建立品牌认知，自然增长

#### 小红书内容矩阵

| 内容类型 | 频率 | 示例 |
|----------|------|------|
| 用户故事 | 2/周 | "她用这个工具处理了500张照片" |
| 仪式教程 | 1/周 | "分手后的照片，3种处理方式" |
| 情感共鸣 | 2/周 | "有些照片，看一眼就想哭" |
| 产品更新 | 1/2周 | "新功能：时间胶囊上线" |

**爆款公式**：
- 钩子（3秒）：痛点场景
- 共鸣（10秒）：情感放大
- 解决方案（10秒）：工具介绍
- CTA（3秒）：链接在哪

#### 抖音短视频

**内容方向**：
1. **"处理过程"可视化** - 录屏展示照片变化
2. **"仪式感"氛围** - 配乐+文字+慢动作
3. **"用户证言"** - 真实用户讲述故事

**注意**：抖音用户注意力更短，前1秒必须抓住

#### 微博话题

- 创建话题 #分手后的照片怎么处理#
- 参与热门情感话题讨论
- 与情感博主互动

### Phase 2: KOL合作（1000-10000用户）

**目标**: 借助影响力快速扩大

#### KOL类型选择

| 类型 | 粉丝量 | 合作方式 | 成本 |
|------|--------|----------|------|
| 情感博主 | 10w-50w | 产品植入 | ¥2000-8000 |
| 心理咨询师 | 5w-20w | 专业背书 | ¥1000-3000 |
| 生活方式 | 10w-100w | 真实体验 | ¥3000-15000 |
| 素人KOC | 1k-1w | 真实分享 | ¥0-500 |

#### 合作策略

**优先找**：
- 有过公开分手经历的博主
- 情感咨询类账号
- 女性成长类账号

**合作形式**：
- 免费体验 + 真实反馈（不要求夸）
- 提供独家优惠码追踪效果
- 长期合作 > 一次性投放

### Phase 3: 增长飞轮（10000+用户）

**目标**: 建立可持续增长模式

#### 1. 用户推荐机制
- "分享给需要的朋友" 按钮
- 推荐奖励：双方各获1次免费高级处理
- 生成可分享的"仪式完成卡"（不含照片，只有文案）

#### 2. SEO/ASO优化

**关键词**：
- 分手照片怎么办
- 删除前任照片
- 合照处理
- 分手后如何放下
- 照片回忆太痛苦

**内容策略**：
- 博客/公众号文章针对长尾关键词
- App Store 描述优化

#### 3. 社区建设
- 微信群：仪式完成后邀请加入（限量）
- 公众号：每周一篇"用户故事"
- 小程序：未来考虑，触达更便捷
